# 🎯 High-Level Purpose (`OBJECTIVE.md`)

## Primary Objective
Build, version, and continuously refine a modular, multi-domain AI agent workflow harness (`sandcastles-skills`) on GitHub that enforces disciplined execution across all coding, content, email, media, and research tasks.

## Key Outcomes
1. **Universal Purpose & Spec Harness**: Every task starts by establishing `OBJECTIVE.md` (high-level purpose) and `SPEC.md` (concrete technical & domain specifications).
2. **Ambiguity Gatekeeping**: Stop and present at least 2 trade-off options whenever task requirements are ambiguous.
3. **Task & Feature Isolation**: Break down features into single isolated tasks with clear boundaries.
4. **Mandatory 5-Line Confirmation**: Require explicit user review and confirmation before applying edits/actions exceeding 5 lines.
5. **Verified Delivery Loop**: Follow the 6-stage lifecycle (Objective $\rightarrow$ Spec $\rightarrow$ Plan $\rightarrow$ Code $\rightarrow$ Verify $\rightarrow$ Outcome Report).
