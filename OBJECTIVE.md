
# 🎯 High-Level Purpose (`OBJECTIVE.md`)

## Primary Objective
Build, version, and continuously refine a multi-domain, multi-provider AI agent workflow harness (`sandcastles-skills`) on GitHub that enforces disciplined execution across all coding, content, email, media, and research tasks across major AI providers (Gemini, Claude/Anthropic, OpenAI, DeepSeek, and Local LLMs).

## Key Outcomes
1. **Multi-Provider Compatibility**: Harness rules, skills, and prompts designed to work seamlessly across major AI models and coding CLI tools (Gemini, Claude, ChatGPT, DeepSeek, Ollama, Cursor/Aider).
2. **Universal Purpose & Spec Harness**: Every task starts by establishing `OBJECTIVE.md` (high-level purpose) and `<topic>-<action>-spec.md` (concrete technical & domain specifications).
3. **Ambiguity Gatekeeping**: Stop and present at least 2 trade-off options whenever task requirements are ambiguous.
4. **Task & Feature Isolation**: Break down features into single isolated tasks with clear boundaries.
5. **Mandatory 5-Line Confirmation**: Require explicit user review and confirmation before applying edits/actions exceeding 5 lines.
6. **Verified Delivery Loop**: Follow the 6-stage lifecycle (Objective $\rightarrow$ Spec $\rightarrow$ Plan $\rightarrow$ Code $\rightarrow$ Verify $\rightarrow$ Outcome Report).
