# Review Skill

This skill governs multi-axis code and architecture reviews.

## Protocol Rules

1. **Multi-Perspective Audit**: Evaluate changes across correctness, security, architecture, readability, and performance.
2. **Spec Verification**: Confirm adherence to `<topic>-<action>-spec.md` and root `SPEC.md`.
3. **Actionable Feedback**: Categorize findings by severity (Critical, Major, Minor).
4. **5-Line Modification Rule**: Present a preview and request follow-up confirmation for review reports exceeding 5 lines.
