# Plan Skill

This skill governs step 1 task planning and feature breakdown.

## Protocol Rules

1. **Input Requirement**: Requires an established `<topic>-<action>-spec.md`.
2. **Task Isolation**: Decomposes the specification into small, isolated, independently testable tasks.
3. **Naming Convention**: Output plan MUST be saved as `<topic>-<action>-plan.md`.
4. **5-Line Modification Rule**: Present a preview and request follow-up confirmation before creating or editing plan files exceeding 5 lines.
