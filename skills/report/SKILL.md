# Report Skill

This skill governs outcome reporting and user sign-off.

## Protocol Rules

1. **Outcome Report Summary**: Summarize completed work, files modified, test verification results, and open items.
2. **Process Documentation**: Update relevant project docs and Architecture Decision Records (ADRs).
3. **User Sign-Off Prompt**: Ask for explicit user sign-off ("yes" / "proceed") before moving to the next task/feature.
4. **5-Line Modification Rule**: Present a preview and request follow-up confirmation for report artifacts exceeding 5 lines.
