# 🏰 Sandcastles Skills (`sandcastles-skills`)

Version-controlled custom skills, rules, and subagent configurations for Google Antigravity.

## 📁 Repository Structure
- `skills/` — Custom workflow skills and runbooks
- `rules/` — Modular tech-stack guidelines (Node/TS, PHP, Python, Go)
- `GEMINI.md` — Global agent behavior standards & ambiguity rules

## 🚀 Usage
This repository is symlinked to `~/.agents` for global discovery across all project sessions.
